Setup & Configuration

  1. Install Meta Common — Website Panel & Shared Tools.
  2. Open Website → Configuration → Settings.
  3. Enable Meta Side Panel on Website.
  4. Set label, position, open mode, and Meta console URLs.
  5. Save, then visit the website — the Meta button appears on every page.
  6. Optional: Website Builder → drop Meta Panel snippet.
